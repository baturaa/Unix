# Unix

Basic (15 команд)

help — справка
man — руководство
history — история команд
clear — очистка терминала
ls — список файлов
cd — переход между папками
pwd — текущий путь
echo — вывод текста
cat — просмотр файла
touch — создание файла
mkdir — создание папки
rm — удаление
mv — перемещение/переименование
cp — копирование
alias — создание сокращений



Text Analyze

tac — вывод файла с конца
head — первые строки
tail — последние строки
find — поиск файлов
grep — поиск текста
awk — обработка текста
sort — сортировка
sed — редактирование текста
cut — извлечение столбцов




System Monitoring 

ps — процессы
top — мониторинг процессов
df — место на диске
du — размер файлов
free — память
kill — завершение процесса
uptime — время работы системы




Networking 
ping — проверка соединения
curl — HTTP-запросы
wget — скачивание файлов
ssh — удалённое подключение
scp — копирование по SSH
rsync — синхронизация файлов



Архивация 
zip — создание ZIP
unzip — распаковка ZIP
tar — работа с TAR-архивами
